# Biblioteca Comunitária

Projeto desenvolvido em Java para a disciplina de Programação Orientada a Objetos (POO).

## Funcionalidades

- Cadastro, consulta, listagem, atualização e remoção de leitores.
- Cadastro, consulta, listagem, atualização e remoção de livros.
- Registro e consulta de empréstimos.
- Registro de devoluções.
- Validação de entradas e regras de negócio.

## Tecnologias

- Java
- Apache NetBeans

## Como executar

1. Abra o projeto no Apache NetBeans.
2. Execute a classe `Aplicacao.java`.
3. Utilize o menu do console para acessar as funcionalidades.
